# Slady

**World of Warcraft: Forever** addon (1.60.x, interface 16001) by **Ob-Went**.

🇵🇱 Rysuje na mapie świata ścieżki, którymi naprawdę przeszedłeś. Loty taksówką są pomijane.

🇬🇧 Draws the paths you really walked on the world map. Flight paths are skipped.

## Features / Funkcje

- Records automatically as you move (grid of visited spots per map)
- Trail drawn as one light layer on the world map
- Pause/resume recording
- Polish and English

## Installation / Instalacja

Copy the `Slady` folder to `World of Warcraft\_forever_\Interface\AddOns\`.

## Commands / Komendy

| PL | EN | |
|---|---|---|
| `/slady pokaz` | `/slady show` | show/hide trails |
| `/slady zapis` | `/slady record` | pause/resume recording |
| `/slady stat` | `/slady stats` | statistics |
| `/slady wyczysc tak` | `/slady clear yes` | delete trails in the current zone |
| `/slady jezyk en` | `/slady lang pl` | language |
